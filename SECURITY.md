# Security Policy

## Reporting Security Vulnerabilities

The Boring Tools team takes security and user privacy seriously. If you discover a security vulnerability or sensitive information exposure (such as an exposed API credential), please report it responsibly.

### How to Report
Please **DO NOT** open a public issue.

Instead, please report it via one of the following methods:
1. **GitHub Private Vulnerability Reporting**: Use the "Report a vulnerability" button in the repository's **Security** tab.
2. **Email**: Send details to `security@boringtoolsai.com` (or contact the maintainer directly).

### What to Include
- Description of the vulnerability
- Steps to reproduce or proof-of-concept
- Potential impact
- Any suggested remediation

We appreciate your effort in making Boring Tools safer for everyone!
